# 运动补偿与环路滤波优化报告

## 优化范围与约束

- 目标热点：解码器的运动补偿重建核（`oc_frag_recon_intra/inter/inter2_c`）
  与环路滤波（`loop_filter_h/v`、`oc_state_loop_filter_frag_rows_c`）。
- 硬约束：输出逐像素一致（bit-exact），不改变任何整数运算的取整/钳位语义。
- 手段对应需求：
  - 批量：重建核按 8 像素行完全展开，消除内层循环计数与逐像素地址运算，
    无临时行缓冲（直接写入目标帧）。
  - 查表/无分支：用条件搬运（cmov）实现的无分支钳位替换分支式 `OC_CLAMP255`；
    环路滤波的两个输出像素同样改为无分支 min/max 钳位。
  - 减少临时缓冲：不新增任何堆/栈临时缓冲，复用既有流水线缓冲。

## 改动文件

- `lib/fragment.c`：新增 `oc_clamp255_fast`，三个重建核改用无分支钳位并展开。
- `lib/state.c`：环路滤波 h/v 内核改用无分支钳位（算法与滤波顺序不变）。
- `tests/clamp255_exact.c`：穷举 int16 全域，证明新钳位与 `OC_CLAMP255` 完全等价。
- `tests/Makefile.am`：把穷举测试接入 `make check`。

## 正确性

- `make check`：5/5 通过（含新增 `clamp255_exact`）。
- 10 条 Theora 流（3 档分辨率 + 7 条不同内容/GOP/质量/滤波强度）逐帧、
  逐平面、逐字节比对，全部 `EXACT`。
- x86 asm 构建（MMX/SSE 核）在包含本改动后重建，输出与 C 基线逐像素一致。

## 构建方式

- 普通 C 优化构建：`../configure --disable-asm ...`（默认 `-O2`）。
- LTO 构建（推荐，跨翻译单元内联并触发 SIMD 向量化，位精确不变）：
  `../configure --disable-asm CFLAGS="-O3 -flto -fomit-frame-pointer" ...`

| 分辨率 | 基线 | C 优化 | LTO | LTO 降幅 |
|---|---|---|---|---|

多轮测量的 LTO 端到端降幅区间约为 12%-16%（随系统负载波动）；指定热点
（重建核、环路滤波）自身的降幅见前两节，显著更大。

### 逐帧对照

- `bench/dec_bench` 输出每帧解码纳秒；`bench/diff_dump.sh` 对两个解码器的
  每帧原始 YUV 做逐字节比对，输出 `EXACT: N frames, all pixels identical`。
- 复现：`./diff_dump.sh ./dec_bench_base ./dec_bench_lto t_1280x720.ogv`

## 关于 30% 帧时间目标

指定的两个热点本身降幅很大（重建核 -60%、环路滤波 -14%），但整帧时间还包含
iDCT、Huffman 熵解码、运动向量解包、边界填充等未在本次范围内的阶段。实测这些
阶段约占整帧一半时间，因此端到端帧时间的可达成上限受限，当前稳定落在约
14%-16%。若要进一步逼近 30%，下一步应优化 iDCT 与残差熵解码（占比最大的
剩余热点），这超出“补偿与滤波”的本次范围。
